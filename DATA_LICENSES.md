# Data licences / Licences des données

## Policy / Politique

- **Produced by PowAtlas** (data, models, documentation): [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/). Code is under [Apache-2.0](LICENSE).
  *Productions du projet (données, modèles, documentation) : CC-BY-4.0. Le code est sous Apache-2.0.*
- **Third-party data** keeps its own licence. Data derived from a share-alike source keeps that licence (e.g. OpenStreetMap → [ODbL](https://opendatacommons.org/licenses/odbl/)).
  *Les données tierces gardent leur licence ; les données dérivées d'une source à partage à l'identique gardent cette licence (ex. OpenStreetMap → ODbL).*
- **A public web page is not a licence.** No data enters the project without a source record (`docs/sources/`) stating its licence, checked on the primary source and dated.
  *Une page publique n'est pas une licence : aucune donnée sans fiche source indiquant sa licence vérifiée et datée.*
